Title (max 255 characters):
CloudGuard AI: a Strands Decider 2B gate that stops an AWS agent acting on thin air

Description (max 512 characters):
CloudGuard AI is an AWS operations assistant that checks every tool call with Strands Decider 2B before it runs, paired with Amazon Bedrock for the generative part. A fail-closed policy the LLM cannot override blocks destructive or ungrounded actions. On a held-out split the decider matched the LLM when confident (92.3%) at about 13x lower cost, with a 0% false-allow rate. Deployed on Amazon Bedrock AgentCore Runtime.
